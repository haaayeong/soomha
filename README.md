# 숨하
## 📖 프로젝트 개요
이 프로젝트의 주제는 미세먼지 빅데이터 분석 및 사전예보 시스템을 구축하는 것입니다.
이 주제를 바탕으로 **어린이, 학부모, 어린이집 종사자들을 위한 미세먼지 사이트**를 개발하고자 했습니다.
사용자들에게 지역별 미세먼지 예측 결과를 알리고, 결과에 따른 놀이 혹은 현장체험 장소를 추천하고, 퀴즈와 데이터 분석을 통해 미세먼지와 관련된 정보를 제공합니다.

## ⏳ 작업 기간 및 내용
- **작업기간** : 3주
- **내용** :
  - 지역별 미세먼지 예측 정보 제공
  - 미세먼지 따라 놀이장소 혹은 체험장소 추천
  - 미세먼지 정보 위주로 구성된 퀴즈 기능 구현
  - 환자 데이터를 이용해 미세먼지의 위험성을 알림.
  - 미세먼지 대비 외출 시 행동요령 정보 제공

## 🚀 설치 및 실행 방법
### 1. 프로젝트 클론
```
git clone https://github.com/haaayeong/soomha.git
```

### 2. 가상환경 설정 및 활성화
- 가상환경 생성
  
 ```
 py -3.11 -m venv dust
 ```

- 가상환경 활성화

```
.\dust\Scripts\activate
```

### 3. 필수 패키지 설치

```
pip install -r requirements.txt
```

### 4. 환경 변수 설정(.env)
- .env 파일 생성 -> 루트 폴더에 위치(dust/.env)

```
FLASK_APP = apps.app
FLASK_DEBUG = True
```
### 5. 데이터베이스 생성(MySQL)
- `soomha` 데이터베이스를 생성합니다.

### 6. 데이터베이스 마이그레이션
만약 `migrations` 폴더에 에러가 발생할 경우, 해당 폴더를 삭제하고 아래 명령어들을 순서대로 입력하여 마이그레이션을 적용합니다.

```
flask db init
flask db migrate
flask db upgrade
```

### 7. 애플리케이션 실행

```
flask run
```
